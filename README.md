# Book Scraper

Python script that scrapes 1000 books (title, price, rating)
from books.toscrape.com and exports them to CSV and Excel.

## Tools
Python, requests, BeautifulSoup, openpyxl

## Usage
pip install requests beautifulsoup4 openpyxl
python scraper.py
python to_excel.py

## Wikipedia Table Scraper
Exports the first table of any Wikipedia page to Excel.

python table_scraper.py <wikipedia-url>
